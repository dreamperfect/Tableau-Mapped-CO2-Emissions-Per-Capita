## Mapped CO₂ Emissions Per Capita:





****Project Description:**** 
Mapped CO₂ Emissions Per Capita (Tableau) — Developed an interactive world map visualizing country-level CO₂ emissions per capita from 2000–2011, using geographic visualization and year-by-year animation to analyze changes and identify high-emission outliers.
